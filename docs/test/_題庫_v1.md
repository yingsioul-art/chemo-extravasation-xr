- 講解-錯：正確答案是中央靜脈導管，因為管徑大、血流快，藥品進入血流立刻被稀釋，外滲風險最低。只有在特殊因素無法使用中央導管時，才改用周邊靜脈。

### 區塊 B｜留置針管徑

**Q3**（表單 3(1)；正解 A）由周邊靜脈注射化療藥品，留置針管徑大小選擇原則是．．．
- A 留置針的號碼越大，代表管徑越小，選擇22 號或更小（≦22 號） ✓
- B 留置針的號碼越小，代表管徑越大，選擇20 號或更大（≧20 號）
- 講解-對：答對了。選 22 號或更細的留置針。針頭細、對血管壁傷害小，也不會擋住針頭下方的血流，藥品才能被血液順利帶走。
- 講解-錯：正確答案留置針的號碼越大，代表管徑越小，選擇22 號或更小（≦22 號）。大管徑的針頭對血管傷害大，而且會阻礙針頭下方的血流，藥品在局部濃度反而更高。
- 圖：s135–136（留置針管徑的選擇）

**Q4**（表單 3(2)；正解 A）周邊注射化療藥品若使用留置針，管徑大小選擇的理由是什麼？
- A 較大管徑留置針對血管傷害大，且會阻礙下方血流 ✓
- B 較小管徑的留置針小針比較不痛，病人接受度高
- 講解-對：答對了。理由就是兩個：一、較大管徑留置針傷血管壁；且針頭下方血流變差，藥品沖不走。兩個都會提高外滲與靜脈炎的機會。
- 講解-錯：正確答案是「較大管徑留置針對血管傷害大，且會阻礙下方血流」
- 圖：s136（目的：減少血管傷害）

- 講解-錯：正確答案是前臂。手背、手腕內側、肘前窩都富含神經與肌腱，外滲一旦發生，傷到的不只是皮膚，是肌腱和神經，後果嚴重得多。

**Q6**（表單 5(2)；正解 A）為什麼手腕內側、手背、腕關節與肘前窩的靜脈要避免注射化療藥品？

**Q7**（表單 5(3)；正解 A）病人右側乳癌術後有右上肢淋巴水腫，左手血管不好找。可以在右手注射化療藥品嗎？
- A 不可以，淋巴水腫的肢體要避免注射化療藥品 ✓
- B 可以，只要回血順暢就好
- 講解-對：答對了。淋巴水腫肢體循環差、組織液回流慢，藥品一旦滲出會蓄積在局部，感染與組織傷害的風險都高。左手找不到血管時，應評估中央靜脈導管，而不是拿右手冒險。
- 講解-錯：正確答案是不可以。淋巴水腫肢體循環差、組織液回流慢，藥品一旦滲出會蓄積在局部，感染與組織傷害的風險都高。回血順暢不能改變回流差的事實；左手找不到血管時，應評估中央靜脈導管，而不是拿右手冒險。
- 圖：s116（水腫肢體）

**Q8**（表單 5(4)(5)；正解 A）病人雙上肢都無法建立周邊靜脈，可以改在下肢（腳背）注射化療藥品嗎？
- A 不建議，下肢末梢循環不佳，藥品容易在局部累積 ✓
- B 可以，腳背血管明顯、容易打，但要抬高下肢
- 講解-對：答對了。下肢末梢循環差，藥品容易在局部累積，外滲與血栓的風險都高。雙上肢都無法建立周邊靜脈，就是中央靜脈導管的適應症。同樣的道理，接受過放射線治療的部位也要避開，因為血管與組織已經受過傷。
- 講解-錯：正確答案是不建議。下肢末梢循環差，藥品容易在局部累積；抬高下肢不能解決循環差的問題。雙上肢都無法建立周邊靜脈，就是中央靜脈導管的適應症。同樣的道理，接受過放射線治療的部位也要避開。
- 圖：s112–117（下肢／放射治療肢體）

### 區塊 D｜外滲徵象辨識

**Q11**（表單 7(1)(2)；正解 A）滴注化療藥品中，病人說注射部位「刺刺的、有燒灼感」，你看到局部皮膚微紅。下一步要怎麼做？

- 講解-錯：正確答案是懷疑外滲，立即停止給藥並評估。疼痛、燒灼感、刺痛、發紅、紅斑，任何一項出現都要懷疑外滲，第一個動作是停止給藥。「再觀察」是外滲處置最常見的延誤；靜脈炎的判斷要在排除外滲之後。停藥不會造成傷害，繼續滴才會。
- 圖：s268–274（燒灼感等徵象）

**Q13**（表單 8；正解 A）懷疑化療藥品外滲，第一個動作是什麼？
- A 立即停止給藥，但不要拔出靜脈留置針，並估計、記錄尚未注入的剩餘藥量 ✓
- B 立即停止給藥並拔針，用紗布壓住止血
- C 先降低滴速，觀察 15 分鐘再決定
- 講解-對：答對了。立即停止給藥，留置針先不要拔，因為它是等一下回抽外滲藥品唯一的路徑。同時看一下點滴袋或注射器，估計還沒注入的剩餘藥量並記錄，這個數字是後面推算外滲量的依據。
- 講解-錯：正確答案是立即停止給藥、不拔針、估計並記錄剩餘藥量。留置針是等一下回抽外滲藥品唯一的路徑，拔掉就沒得抽；降速觀察只是讓更多藥品進入組織。剩餘藥量要當下記，之後推算外滲量才有依據。
- 圖：s289–293（立即停止給藥）

**Q14**（表單 9；正解 A）處理外滲時要穿戴哪些防護裝備？
- A 防水隔離衣（後開式、長袖、袖口可束緊）、雙層丁腈或乳膠手套並套住袖口、外科口罩；有噴濺風險時加護目鏡或防護面罩 ✓

- C 只要戴手套就可以，因為藥量很少

- 講解-錯：正確答案是防水隔離衣、雙層手套套住袖口、外科口罩，有噴濺風險時加護目鏡或面罩。一般隔離衣不防水、單層手套不夠；藥量少不代表沒有暴露，回抽時噴到手、噴到眼的機會就在這幾分鐘。

**Q15**（表單 10、11；正解 A）停止給藥後，接下來要怎麼做才能把外滲的藥品抽出來？
- A 移除裝有剩餘化療藥品的注射器或輸液套管，接上無菌 10 mL 注射器，從原靜脈注射處盡可能回抽到抽不出來為止，並估計回抽量 ✓
- B 直接用原本的注射器往回抽
- C 拔針後用針筒從皮下抽
- 講解-對：答對了。先把還裝著化療藥品的注射器或輸液套管拆掉，換上一支無菌 10 mL 空針，從原來的留置針盡可能回抽，抽到抽不出來為止，並估計回抽出的外滲藥量。這就是為什麼前面不能先拔針。
- 講解-錯：正確答案是換上無菌 10 mL 空針，從原留置針盡可能回抽並估計回抽量。原本的注射器裡還有藥，回抽會混在一起算不出量；拔針後從皮下抽會造成新的傷口，也抽不到血管內殘留的藥。
- 圖：s291–293（接上注射器，儘可能回抽）

**Q16**（表單 12；正解 A）回抽完成後，留置針要怎麼處理？
- A 看有沒有解毒劑：有解毒劑就依醫囑準備，由醫師從原靜脈注射處注射後再拔針；沒有解毒劑就直接拔針 ✓
- B 一律立刻拔針
- C 一律保留留置針 24 小時觀察
- 講解-對：答對了。拔不拔針取決於有沒有解毒劑。有解毒劑，原來的留置針就是醫師給解毒劑的路徑，要等注射完再拔；沒有解毒劑，就把針拔掉。本院目前多數化療藥品沒有解毒劑，實務上大多是回抽後拔針。
- 講解-錯：正確答案是依解毒劑有無決定：有就由醫師從原針注射解毒劑後再拔，沒有就直接拔針。一律立刻拔會把解毒劑的給藥路徑拔掉；一律保留 24 小時則讓一支已經不在血管內的針留在組織裡，沒有好處。
- 圖：s305–309（醫療處置：解毒劑）、s312（移除針具）

**Q17**（表單 13；正解 A）外滲部位可以用手壓迫止血或按壓嗎？
- A 不可以，壓迫會讓外滲藥品擴大浸潤到周圍組織，起疱性藥品尤其危險 ✓
- B 可以，跟一般拔針一樣壓緊止血
- 講解-對：答對了。外滲部位不要壓。壓迫會把已經在皮下的藥品推開，浸潤範圍變大，起疱性藥品一擴散就是更大面積的組織壞死。拔針後用紗布輕輕覆蓋即可。
- 講解-錯：正確答案是不可以壓迫。這跟一般拔針不同，皮下有藥品時一壓就把藥推開，浸潤範圍變大；起疱性藥品一擴散就是更大面積的組織壞死。拔針後用紗布輕輕覆蓋即可。
- 圖：s304、s312–313（勿壓迫／紗布覆蓋）

**Q18**（表單 14；正解 A）為什麼要用油性筆把外滲範圍標示出來？
- A 標出當下的外滲邊界，之後才能比較範圍有沒有擴大，也是拍照與交班的依據 ✓

- 講解-錯：正確答案是標出當下的外滲邊界，供後續比較與拍照交班。油性筆的線是「現在」的記號，之後每天觀察、拍照、交班都拿它比對範圍有沒有擴大；用油性筆是因為不會被汗水或敷料擦掉。
- 圖：s325（限制藥品擴散到周圍組織）※待核是否有油性筆畫面

**Q19**（表單 15；正解 A）外滲部位要冰敷還是熱敷？
- A 依外滲的藥品種類決定，要查「各類化療藥品外滲處置方法」 ✓
- B 一律冰敷，因為可以消腫止痛
- C 一律熱敷，因為可以促進吸收
- 講解-對：答對了。冰敷或熱敷不是看腫不腫，是看藥品。多數起疱性藥品用冰敷讓藥品局限在局部；少數藥品（例如 Vinca alkaloid 類、Oxaliplatin）反而要熱敷幫助擴散吸收，冰敷會加重傷害。所以一定要查表，不憑印象。
- 講解-錯：正確答案是依藥品種類決定並查表。冰敷或熱敷不是看腫不腫，是看藥品：多數起疱性藥品用冰敷，但 Vinca alkaloid 類與 Oxaliplatin 要熱敷，用錯方向會加重傷害。不憑印象，查「各類化療藥品外滲處置方法」。
- 圖：s316–322、s329–332（敷療／敷療方式）

**Q22**（表單 18；正解 A）病人住院期間，外滲部位每天要觀察並記錄哪些項目？若症狀沒有改善要怎麼辦？

**Q26**（表單 22；正解 A）外滲事件的異常事件通報，誰在什麼時候完成？
